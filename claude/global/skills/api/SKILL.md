# /api — API 엔드포인트 개발

인수: $ARGUMENTS

## 따를 규칙

- 공통 원칙(API 설계, 인증·인가, 데이터, 테스트 계층): `~/.claude/rules/web.md`
- 작업 방식(재진술, 검증 보고, 범위 준수): `~/.claude/rules/core.md`
- 프로젝트 CLAUDE.md·`.claude/rules/`·언어 프로필 rules가 web.md보다 우선한다.
- 여러 모듈에 걸친 구현을 나누어 맡길 때는 `/delegate`를 따른다. 마이그레이션은 메인이 직접 다룬다.

## 절차

1. 요구사항 재진술 — 인수가 파일 경로면 그 파일을 읽는다. 아래 양식으로 정리해 보여준다.

   ```text
   목표: <무엇을 왜, 한두 문장>
   요구사항:
   - <엔드포인트·동작 단위로 하나씩>
   유의사항:
   - <반환 필드, 필터·페이지네이션 규칙, 부분 수정 여부, 테스트 도구 등 제약>
   완료 조건:
   - <통과해야 할 테스트, 문서 갱신, 검증 명령>
   가정·질문:
   - <모르는 것. 막히면 질문, 아니면 가정을 명시하고 진행>
   ```

2. 기존 패턴 확인 — 새 방식을 만들지 않고 저장소의 방식을 따른다.
   - Grep으로 같은 자원이나 가장 비슷한 엔드포인트를 찾아 끝까지 읽는다: 라우팅, 요청·응답 스키마(직렬화), 검증, 권한, 에러 응답 형식, 페이지네이션·필터 구현, 서비스 계층, 테스트 스타일.
   - 프로젝트 CLAUDE.md의 명령어(테스트·린트)와 컨벤션을 확인한다.
   - 확인한 근거는 경로:라인으로 남긴다.
3. 명세 표 — 엔드포인트마다 한 행. 공개(비인증) 엔드포인트는 명시적으로 표시한다.

   | 메서드 | 경로 | 요청(필드·검증 규칙) | 응답(필드·상태 코드) | 에러(상태 코드·code) | 권한 | 목록 규약(페이지네이션·필터·정렬) |
   |---|---|---|---|---|---|---|

   - 상태 코드와 에러 형식은 web.md와 기존 엔드포인트에 맞춘다.
   - 응답에 내부 식별자·비밀 필드(토큰, 키, 비밀번호 해시 등)를 넣지 않는다. 쓰기 전용 필드는 응답에서 뺀다.
   - 부분 수정(PATCH)은 받은 필드만 바꾸는지, 멱등성이 필요한지 적는다.
4. 플랜 승인 후 구현 — 여러 파일을 바꾸면 변경 파일 목록과 순서를 보여주고 승인받는다.
   - 구현 순서: 모델·스키마 → 서비스(비즈니스 로직) → 라우트·뷰(얇게) → 직렬화·입력 검증 → 권한 → 문서(OpenAPI 주석·데코레이터·스키마 파일).
   - 트랜잭션 경계는 서비스 계층에 둔다. 목록 조회는 N+1이 없게 한다.
   - 마이그레이션이 필요하면 생성·적용 전에 사용자에게 확인한다. 이미 적용된 마이그레이션은 고치지 않고 새로 만든다(guard-migrations 훅이 확인을 요구한다). 파괴적 변경은 2단계로 나눈다(web.md).
   - 의존성 추가는 사용자 확인 후.
5. 테스트 — 엔드포인트마다 작성한다.
   - 성공 경로(상태 코드·응답 필드).
   - 실패: 검증 오류(필수 누락, 형식 오류, 허용되지 않은 필드).
   - 권한: 비인증 401, 권한 없음 403, 다른 사용자 자원 접근.
   - 경계값: 빈 값, null, 최대 길이·크기, 존재하지 않는 id(404).
   - 목록: 필터 조합, 정렬, 페이지네이션(첫·마지막 페이지, 페이지 크기 상한).
   - 외부 API는 mock. 실행은 프로젝트 CLAUDE.md의 테스트 명령으로, 한 시점에 하나씩(DB·포트 공유).
   - 실패하면 원인을 고치고 다시 실행한다. 테스트를 약화하거나 건너뛰지 않는다.
6. 보고

   | 메서드 | 경로 | 상태 | 테스트 |
   |---|---|---|---|

   - 변경 파일, 실행한 검증 명령과 결과 요지.
   - 미검증: 실행하지 못한 테스트, 확인하지 못한 가정.
   - 범위 밖 발견: 고치지 않고 목록만.
   - 마이그레이션·문서(OpenAPI) 변경 여부. 커밋 전 점검은 `/preflight`, 리뷰는 `/review-diff`를 제안한다.
